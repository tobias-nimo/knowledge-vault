# ML Project Checklist
This checklist provides a structured workflow for tackling Machine Learning projects. There are eight main steps:
1. [[Look at the Big Picture]]—frame the problem and check assumptions.
2. [[Get the Data]]—build a script to automatically load the data and split it into a training and test sets.
3. [[Explore the Data]]—look for correlations and use with different plots to visualize patterns.
4. [[Prepare the Data]]—write a preprocessing pipeline to automatically clean up and transform the data for ML algorithms. 
5. [[Explore Different Models]]—train and evaluate a set of candidate models. 
6. [[Fine-tune]]—optimize the most promising models and select the best solution.
7. [[Present the Solution]]—communicate the results and key findings.
8. [[Launch, Monitor, and Maintain]]—deploy the model in production and monitor its performance over time.

This workflow works well for most Machine Learning projects, but it should be adapted to fit the specific requirements and constraints of your problem.

For a **complete end-to-end example**, follow the companion [Jupyter notebook](https://github.com/ageron/handson-mlp/blob/main/02_end_to_end_machine_learning_project.ipynb). It walks through a realistic project scenario in which you play the role of a newly hired data scientist at a real estate company.
