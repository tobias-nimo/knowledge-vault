# ML Project Checklist
This checklist provides a structured workflow for tackling Machine Learning projects. There are eight main steps:
1. [[Look at the Big Picture]]
2. [[Get the Data]]
3. [[Explore the Data]]
4. [[Prepare the Data]] 
5. [[Explore Different Models]]
6. [[Fine-tune]]
7. [[Present the Solution]]
8. [[Launch, Monitor, and Maintain]]

This workflow works well for most Machine Learning projects, but it should be adapted to fit the specific requirements and constraints of your problem.

For a **complete end-to-end example**, follow the companion [Jupyter notebook](https://github.com/ageron/handson-mlp/blob/main/02_end_to_end_machine_learning_project.ipynb). It walks through a realistic project scenario in which you play the role of a newly hired data scientist at a real estate company.
