# Knowledge Vault

A personal knowledge base synced with my Obsidian vault — a growing collection of notes from books, papers, and courses I'm studying.

## Topics

Notes are grouped into three sources:

- **📚 Books** — notes from technical books
- **📝 Papers** — notes from papers and whitepapers
- **🎓 Courses** — notes from courses

See **[INDEX.md](INDEX.md)** for the full list of what's covered under each.

## Structure

Notes are organized by source (`books/`, `papers/`, `courses/`) and then by topic. A folder may contain:

- Markdown files (`.md`) — primary notes
- Jupyter notebooks (`.ipynb`) — code examples and experiments
- Figures (`figures/`) — diagrams and images referenced by the notes

## Usage

This repository is designed to work with [**Obsidian**](https://obsidian.md/), but the markdown files are readable on GitHub or in any text editor.
