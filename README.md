# Knowledge Base

A personal knowledge base synced with my Obsidian vault. This is a growing collection of notes on topics I'm learning.

## Topics

- **Prompt Engineering** - Notes on LLM prompting techniques
- **StatQuest** - Statistics and machine learning concepts
- ...

## Structure

Notes are organized by topic in folders. Each folder may contain:
- Markdown files (`.md`) - Primary notes
- Jupyter notebooks (`.ipynb`) - Code examples and experiments

## Usage

This repository is designed to work with [**Obsidian**](https://obsidian.md/), but the markdown files are readable on GitHub or any text editor.
